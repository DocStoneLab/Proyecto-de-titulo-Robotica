# Programa Basico para mover un robot con un Puente H
El puente H es el [Módulo Driver para 4 Motores DC Puente H Dual](https://altronics.cl/modulo-l293d-dual)
Por el mal estado de el puente H ahora usaremos 2 [puentes H L298N ](https://arduino.cl/producto/controlador-de-motores-puente-h-l298n/?srsltid=AfmBOoqpF86OFQ5iiVy2pLeQmpeu0yWEnP563d3MZyG2fX-jYN5vS229)
